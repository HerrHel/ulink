与链浏览器扩展（内测 · 实验性功能）

用于 B站/抖音/小红书的「视频深度解析」：扩展只读取你当前打开的页面里已有的播放地址， 使用你自己的浏览器 IP 与登录态，不额外登录平台、不经过代理。

这是实验性实验室功能，不是主套餐的固定承诺：需要手动安装扩展、仅桌面端可用， 平台改版或风控变化时可能失败或下线；B站为正式支持，抖音/小红书为实验性且不保证可用。

支持情况（诚实标注）

  • B站正式支持：读取页面 __playinfo__，口播转写 + 画面网址。
  • 抖音实验性：依赖页面态，未登录/触发验证码/页面改版时可能失败。
  • 小红书实验性：通常需要登录，可能拿不到视频地址。
  • 其它平台：仍走原有解析链路，不需要扩展。

安装（Chrome / Edge，开发版）

  1. 打开扩展目录：github.com/HerrHel/ulink/tree/main/extension；
  2. 下载整个 extension 目录到本地；
  3. 浏览器地址栏打开 chrome://extensions（Edge 为 edge://extensions）；
  4. 打开右上角「开发者模式」→「加载已解压的扩展程序」→ 选择 extension 目录；
  5. 安装后在 与链 登录一次（扩展与网页共用登录态）。

正在准备商店上架；当前为开发版，需要手动加载。扩展只申请 activeTab / scripting / storage 等必要权限，不会读取你未主动解析的页面。

怎么用

  1. 在 B站/抖音/小红书打开一个视频页；
  2. 页面空白处右键 →「与链：深度解析此视频」；
  3. 新标签页会显示进度、口播转写和画面中出现的网址；
  4. 解析消耗实验性深度解析体验额度（每日 2 次，可能调整）。

如果提示「页面没有暴露播放地址」：B站请刷新/登录后重试；抖音请先在网页版登录并播放一次——抖音适配仍是实验性， 不保证所有视频可用。我们不会为此伪造结果。

实验性功能可能随平台改版、浏览器政策或成本变化随时调整或下线，不构成付费套餐的固定承诺； 如无法接受请勿为此单独升级 PRO。
