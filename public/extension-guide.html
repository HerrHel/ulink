与链浏览器扩展与视频解析说明

扩展现在只负责「保存当前页面/选中文本到与链」；平台视频深度解析已下线。需要分析视频/音频/图片时，直接在 AI 聊天框上传文件即可。

聊天媒体解析（新方式）

  1. 打开 与链 并登录；
  2. 在 AI 输入框点「+」上传图片/视频/音频；
  3. 正常提问（如“总结这个视频”“截图里有哪些网址”）；
  4. AI 会根据你的问题自动选择直接看图，或做口播转写/画面 OCR，处理完即删除文件。

不需要浏览器扩展、不需要代理、不抓取第三方平台；支持音频 ASR、视频 ASR+OCR、图片 OCR。 实验性功能，每日体验额度有限。

扩展安装/更新（仅保存功能）

  1. Edge 用户：在 Edge 加载项商店搜索「与链」并更新到最新版本；
  2. Chrome 用户：在 Chrome Web Store 搜索「与链」；
  3. 开发版：下载 extension 目录 → edge://extensions / chrome://extensions → 开发人员模式 → 加载解压缩的扩展；
  4. 安装后在 与链 登录一次。
