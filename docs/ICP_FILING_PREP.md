## 三、可复制文案

**网站名称**（表单官方提示：**单位备案推荐使用单位全称或简称及商标**；湖北要求与字号/经营范围相关）：
```
首选：营业执照字号全称（如「武汉市××区××信息服务部」）——最稳，不会因"名称与主体无关"被驳回
次选：字号简称（字号含「与链」时可直接用「与链」）
备选：「与链书签」——仅当字号含「与链」或已注册「与链」商标时使用；否则被驳回风险高
```
> 不要在网站名称里用「平台 / 商城 / 论坛 / 社区」等词。

**网站简介 / 备注**：
```
与链（ulink）是个人书签管理工具，为用户提供网址收藏、分类整理、多端同步与个人收藏集分享功能。用户注册后可保存自己收藏的网页链接，并进行分类整理与跨设备同步。网站为工具类应用，不包含新闻资讯、论坛社区等内容，不涉及前置审批事项。
```

> ⚠️ 简介里**不要出现**这些词（湖北会触发额外材料/前置审批）：商城、电子商务、网上销售/零售/贸易、直播、网络音乐、演出、动漫、教育、医疗、药品。上面文案已全部避开。

## 四、湖北个体户专属材料（最容易翻车的地方）

> 上传位置：备案表单**第 3 步「补充材料上传」→ 其他材料**（页面写"选填"，但湖北个体户这几项初审必查，**建议主动传**，省一轮驳回重排队）。格式仅 jpg/jpeg/png/avi/mp4/mov/gif、≤9M，PDF/Word 不支持——书面材料打印签字盖章后**拍照**上传。

湖北管局规则：**「注册资本 <50 万且法人户籍非湖北」的企业（含个体户）；个体工商户无注册资本的，视同本类型处理 → 备案时须提供企业真实经营证明材料。**

需要准备：

1. **经营真实性证明（三选一）**
   - 纳税证明 / 社保·医保·公积金缴存证明 / 工商年报
   - **例外：个体户成立未满 3 个月**且拿不出上述证明 → 可用**办公地址佐证**（租赁合同 / 房产证等）替代
2. **真实性承诺书**：经营者**手写签字 + 加盖公章**（无固定模板，自己写一段承诺内容即可）
3. **营业执照必须"有字号、有公章"**——无公章先去刻章（个体户刻章一般当天可取）

另需常规材料：
- 营业执照原件拍照（清晰、完整、不反光）
- 经营者身份证**正反面**原件拍照（有效期 >3 个月，正反面背景一致）
- **域名证书**（腾讯云域名控制台可下载；域名有效期 >3 个月，我们自动续费 ✅）
- 人脸核验（腾讯云备案小程序扫脸）+ 手机短信核验

## 六、提交后

1. 腾讯云初审 1–2 个工作日（可能电话回访）
2. 管局审核 1–20 个工作日（湖北以严格著称，材料一次备齐最省时间）

4. 备案期间**保持关站**，不要临时开解析"看看效果"——管局会核查

## 附录二：电子商务情况说明书（被要求补交时用）

> 触发原因：营业执照经营范围含「互联网销售/网上销售」等词，或网站备注出现电商类关键词。管局要的是**现状事实陈述**，不是商业计划。

```
电子商务情况说明书

网站内容为单位门户网站（个人书签管理工具），不涉及第三方商家入驻，
无第三方付款。如有涉及，一切责任自行承担。


                        经营者（签字）：____________

                                （加盖公章）

                        日期：______年____月____日
```

**写法铁律**：
- 逐字贴近官方模板，只补一处与备案信息一致的站点性质说明
- **不要写"若未来开展线上销售…"**——主动引入不存在的业务，且与当前非经营性备案定性冲突
- 避开触发词：线上销售、售卖、交易平台、撮合、电商、ICP 许可证、增值电信
- 有公章盖章；个体户无公章 → 法定代表人手写签字（模板明确允许）

**关于未来盈利（已核实口径）**：备案材料不构成对未来的承诺，将来开展经营性业务按当时规则办即可，不会因为本说明书未写未来规划而受阻。
- 自营卖自有商品（实物）：通常不需要 ICP 许可证（不属于"有偿信息服务"）
- 第三方平台（商家入驻/撮合交易）：需要 EDI 许可证（在线数据处理与交易处理）
- **有偿信息服务（会员订阅/付费功能）：灰色地带**——可能被认定为经营性互联网信息服务，届时需评估办理 ICP 许可证或经营性备案变更
