# 浏览器扩展路线图

> 制定于 2026-11-25。扩展 2.0（侧边栏 = 主站 iframe 壳）已提交 Edge 商店审核。

## 定位

扩展是与链伸进浏览器的「手」，不是独立产品。

**准入标准**：功能必须同时满足下面两条，否则放主站，扩展不重复实现。

- **需要浏览器上下文**：当前标签页、划选文字、登录表单、快捷键或工具栏图标。
- **够快**：1–2 秒内完成，不离开当前网页。

**能力分三层**：

1. **收**：随手采集网页。
2. **认**：浏览时想起「我在这里存过什么」。
3. **帮**：顺手辅助，例如存密码、记视频时间点。

**成功标志**：

- 日常打开与链的入口以侧边栏为主。
- 新增书签多数来自扩展。

## 版本路线

| 版本 | 主题 | 是否要发扩展新版 | 新增权限 |
|---|---|---|---|
| 2.0 | 侧边栏 = 主站，原地保存 | 是（审核中） | — |
| 2.0.x | 「认」：本站回想（已完成） | **否**，只改主站 | 无 |
| 2.1 | 存网站密码 + 划词/悬浮保存 | 是 | 可选 `<all_urls>`，一次同意 |
| 2.2 | 视频字幕摘要 + 多商店上架 | 是 | 无 |
| 2.3 | 侧边栏阅读视图 + 密码代填 | 视功能而定 | 复用 2.1 |

### 2.0：上架与观测

- **上架后**：确认已安装的 1.x 用户能自动更新到 2.0，侧边栏能正常加载主站。
- **观测侧边栏保存量**：主站本地统计各保存入口的次数（侧边栏 / 网页版），不上传网址，只计数。用这个数据判断后续版本有没有提升。

### 2.0.x：「认」的第一步（审核期即可开工）

这一步只改主站：侧边栏就是主站页面，主站部署后立即生效，不过商店审核。

- **本站回想（已完成，2026-11-25）**：侧边栏「当前页面」卡片下方列出同一网站存过的书签（同主机或父子域名，兄弟子域不算），例如「你在 github.com 存过 3 条」，附备注摘要，默认显示 3 条可展开，点击即打开。实现：`src/lib/siteRecall.ts` + `ExtPanelCurrentPage.vue`。
- **相关提示（暂缓）**：当前网站没存过时提示同类网站。不调 AI 就不知道当前页属于哪个分类，规则推断效果差，等 AI 预填结果可复用时再做。
- **工具栏弱提示（移到 2.1）**：同网站有收藏时在图标上弱提示。需要扩展识别新消息字段，要发扩展新版，随 2.1 一起发。

### 2.1：存网站密码 + 划词/悬浮保存

两个功能共用一次 `<all_urls>` 可选权限申请和单独同意，合在一个版本发布。

**存网站密码**：方案见记忆 `extension-2-1-password-plan`，要点：

- **P0 验证**：网页里的扩展 iframe 提示框，能否在用户点击时直接 `sidePanel.open`。
- **E2E 前置**：未开端到端加密时不存密码。新链路要断言 `saveBm` 绝不走 base64 分支。
- **只显示少量信息**：提示框只显示域名和用户名，加密与存储都交给主站书签弹窗。

**划词气泡 / 悬浮按钮**：

- **默认关闭**：在设置里开启，支持「在此网站隐藏」。
- **隔离**：按钮放在扩展自己的 iframe 里，网页读不到也改不了。
- **保存链路**：点击后打开侧边栏，复用 `PANEL_SAVE` 链路。

**权限迁移**：`<all_urls>` 只能放进 `optional_host_permissions`。放进必选权限的话，老用户更新时扩展会被浏览器停用。

**同步修改**：隐私政策、商店隐私声明（勾「身份验证信息」）、商店描述、`/extension-guide.html`。

**待决定**：同意记录是否上云。

### 2.2：视频字幕摘要 + 多商店上架

**视频字幕摘要**：

- **读什么**：用户点击时，借 `activeTab` 读取页面上**已经显示出来**的字幕、标题和简介，交给主站 AI 摘要，写进备注。
- **不碰播放地址**：不读播放地址，不下载媒体，避免重走 2026-11 已下线的深度解析老路。
- **口播转写**：仍然引导到主站「上传媒体解析」。

**多商店**：

- **Chrome 应用商店**：需开发者账号。
- **Firefox AMO**：代码已兼容 `sidebarAction`，需补 Firefox 的扩展 ID 与 `EXT_FRAME_ORIGINS` 网关白名单。

### 2.3：阅读视图 + 密码代填

**侧边栏阅读视图**：

- **展示内容**：点击书签时，侧边栏不嵌原网页，而是显示主站提取的正文、摘要和你的笔记，再给一个「在新标签打开」。
- **实现位置**：主站功能，扩展基本不用改。

**密码代填**：

- **流程**：在登录表单里点「用与链填写」→ 侧边栏解锁 E2E → 只把当前域名匹配的那一条凭据交给内容脚本填写。
- **上线前**：需单独做安全评审，至少包括钓鱼域名匹配、iframe 内表单、自动提交防护。

## 明确不做

- **内置浏览器**：在侧边栏嵌任意网站会遇到三个问题。
  - 大量网站禁止被嵌入，嵌进去是空白页。
  - 删响应头绕过属于削弱网站安全，审核是红线。
  - 嵌入后登录态经常带不过去。
- **平台视频深度解析**：例如读 `__playinfo__`、钩接口拿播放地址。原因有两个：
  - 有版权和平台条款风险。
  - 平台一改版就失效。
- **重复实现主站功能**：管理、编辑、搜索、设置一律走侧边栏里的主站。
- **与书签无关的工具**：例如广告拦截、截图、翻译。

## 每次发版的检查项

- **权限**：manifest 权限只增不改，新增权限一律走 optional。
- **协议同构**：`extension/panel-bridge.js` 与主站 `src/lib/extPanel.ts` 协议同构，改一侧必须改另一侧并跑双方测试。
- **嵌入白名单**：新增的商店扩展 ID 要同时加进网关 `frame-ancestors` 和 `edge-headers` 的 `EXT_FRAME_ORIGINS`。
- **文案同步**：商店描述、隐私声明、`/extension-guide.html`、AGENTS.md「浏览器扩展」一节同步更新。
