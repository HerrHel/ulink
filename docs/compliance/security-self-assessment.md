## 二、是否属于评估范围的判定

《安全评估规定》第三条第（一）项列举的"信息分享"功能，本服务在形式上**附设了相应功能**（用户可将自己的书签/笔记以私有链接形式分享给他人），因此按本规定主动开展自评估。

同时，本服务的分享功能具备以下限定，**不具备面向公众的舆论表达与动员能力**：

1. **非公开广场**：不存在首页信息流、热门榜、推荐位、话题聚合、评论区、关注/粉丝关系、私信群发；
2. **访问受控**：分享须由用户主动开启，链接为随机标识的私有链接，仅持有链接者可访问，可设置访问密码；用户可随时关闭分享，链接立即失效；
3. **不可检索**：分享页在服务端每次响应中显式声明 `noindex, nofollow`，不进入搜索引擎索引，不出现在任何公开列表；
4. **单向只读**：访问者只能查看内容，不能评论、不能二次发布、不能向其他用户分发；
5. **无公众账号体系**：不存在面向公众持续发布内容的账号形态。

服务性质为**个人知识管理工具的私有分享**，性质接近网盘的定向分享，不构成公众舆论场。

## 四、用户身份与账号管理（第五条第（二）项）

1. **账号注册**：以邮箱地址 + 邮箱验证码方式注册，一个邮箱对应一个账号；
2. **密码安全**：密码以不可逆哈希存储，服务端不可还原；
3. **交易身份核验**：订阅付费通过微信支付、支付宝完成，交易主体身份由支付机构的实名账户体系核验，订单与渠道流水号可追溯；
4. **账号处置**：用户可自助注销，注销后云端数据立即删除、账号记录 3 个工作日内移除；违规账号可被限制功能或封禁；
5. **权限最小化**：用户仅能读写本人数据，服务端以行级安全策略（RLS）强制隔离，越权请求由数据库层拒绝。

## 五、信息发布审核与巡查（第五条第（二）（三）项）

### 5.1 发布环节

本服务无公开内容池，用户创建的书签与笔记默认仅本机保存，**未经用户主动开启云同步与分享，服务端不持有其内容**。分享为私有链接，属于用户点对点传递。

### 5.2 审核与巡查

1. **技术措施**：富文本内容经白名单净化后才渲染，禁止脚本、iframe、内联事件等可执行内容，杜绝挂马与脚本注入传播；
2. **人工巡查**：信息审核责任人每日对分享页可访问性做抽查，每周复核举报处置记录；
3. **举报受理**：分享页底部设「举报 / 侵权投诉」入口，同时开放受理邮箱 herr@ulink.ren；受理后 24 小时内初步核实，48 小时内作出处置决定；
4. **处置措施**：确认违规的，立即关闭分享链接、删除内容、视情节警告/限制功能/封禁账号，并保存原始记录不少于 6 个月；
5. **报告义务**：属于《计算机信息网络国际联网安全保护管理办法》第四条至第七条情形的，保留原始记录并在 24 小时内向属地公安机关报告。

### 5.3 内容规则

《用户服务协议》第四条明确禁止发布违法违规信息，并约定平台的处置权；禁止范围覆盖《互联网信息服务管理办法》第十五条所列全部情形。

## 六、技术安全措施（第五条第（三）（四）项）

| 类别 | 措施 |
|---|---|
| 传输安全 | 全站 HTTPS，启用 HSTS（max-age=31536000） |
| 页面安全 | CSP（`default-src 'self'`）、`X-Content-Type-Options: nosniff`、`X-Frame-Options: SAMEORIGIN`、`frame-ancestors 'self'` |
| 访问控制 | 行级安全策略（RLS）；公开读取仅经服务端白名单接口；管理凭证单独保管 |
| 数据加密 | 书签用户名端到端加密（AES-256-GCM，密钥由用户设备派生，服务端无明文密钥） |
| 接口防护 | 人机验证（无感工作量证明 + 图形验证码兜底）、按 IP 与账号双维度限流 |
| 输入防护 | 输入统一转义；笔记富文本白名单净化；上传文件类型与大小校验，处理完即删除 |
| 供应链 | 依赖定期升级，构建流水线执行漏洞扫描，高危阻断发布 |
| 日志 | 网络访问日志留存不少于 6 个月；错误日志最长 12 个月；内容处置记录不少于 6 个月 |

## 七、个人信息保护（第五条第（四）项）

1. **最小必要**：仅收集提供服务必需的信息（邮箱、加密后的书签与笔记、订单信息），不接入广告 SDK；AI 功能会在端侧归纳生成个人记忆与长期偏好画像及心智模型画像（领域专注度、价值取向与审美倾向），该等画像在端侧生成、随 AI 请求一并外发，已在《隐私政策》3.3 完整清单中如实列明；
2. **告知同意**：处理规则、目的、保存期限、第三方共享情形（AI 服务商、支付机构、云服务商）在《隐私政策》中逐项列明；
3. **第三方共享**：AI 功能提交第三方处理的数据以《隐私政策》3.3 完整清单为准，除对话内容、多轮上下文与为回答所必需的书签片段（标题、网址、备注、分类名称）外，还包括全部分类与标签名称、当前分类视图及聚焦工作台、多选勾选书签、端侧本地检索召回的内容片段、个人记忆与心智模型画像、全部工具定义、随提问附加的图片音视频，以及按提问关键词触发的情境注入等；主对话经境内服务端转发至境内第三方大模型服务商，意图寻站、网页元数据提取与海外可达性探测等链路的 URL、公开页面元数据及部分提示词内容则由境外边缘节点（Cloudflare）处理，各链路接收方与处理地点在《隐私政策》3.1、3.3 逐项列明；
4. **用户权利**：提供查阅、更正、删除、导出、注销的完整路径，请求 15 个工作日内答复；
5. **境内存储**：业务数据（账号信息、云同步的书签与笔记、分享图片、订单与用量记录等）存储于境内（腾讯云上海地域）；境外边缘节点（Cloudflare）仅为完成意图寻站、网页元数据提取与海外可达性探测，处理待解析网页的 URL、页面公开元数据及部分提示词内容，形成与境内业务数据存储相分离的境外处理链路，相关情形已在《隐私政策》3.1、3.3 单独披露；

## 九、自评估结论

1. 本服务附设"信息分享"功能，按《安全评估规定》主动开展评估；服务形态为私有链接点对点分享，无公开内容池、无评论与关注关系、不可被搜索引擎检索，**不具备形成公众舆论场与发动社会公众从事特定活动的能力**。
2. 已建立安全管理责任体系（负责人、审核、应急三岗，由经营者兼任并留痕）、账号与权限管理制度、内容审核与举报处置流程、日志留存制度、应急处置预案。
3. 已落实传输加密、页面安全策略、行级访问控制、端到端加密、人机验证与限流等主要技术措施。
4. 个人信息处理遵循最小必要原则，规则公开、权利路径完整；业务数据存储于境内，境外边缘节点仅处理必要的 URL、公开页面元数据与部分提示词内容。

**评估结论：已完成安全评估，现有管理与技术措施能够防范、制止违法信息传播，安全风险可控。**

**待持续改进项**（不影响本次结论）：

1. 用户身份核验目前依赖邮箱验证 + 支付渠道实名，随用户规模增长将补充手机号验证；
2. 日志留存期限的技术配置与实际保留策略保持同步核查，确保不少于 6 个月；
3. 随功能迭代同步更新本报告与配套制度。
