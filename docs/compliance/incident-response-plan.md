## 一、适用与目标

本预案适用于本网站发生的信息安全事件（数据泄露、服务中断、网页篡改、违法信息传播、账号被盗、支付异常等）的监测、报告与处置。

目标：

1. 第一时间控制事态，避免影响扩大；
2. **按规定 24 小时内向属地公安机关报告**；
3. 保护用户个人信息，履行告知义务；
4. 保留证据，配合调查。

## 三、事件分级

| 级别 | 判定标准 | 响应时限 |
|---|---|---|
| **Ⅰ 级（特别严重）** | 用户数据批量泄露；网站被篡改出现违法内容；服务全面不可用超 2 小时 | 立即处置，**24 小时内报告** |
| **Ⅱ 级（严重）** | 单一用户数据泄露；分享页出现违法有害信息；核心功能（登录/同步）不可用 | 2 小时内处置，24 小时内报告 |
| **Ⅲ 级（一般）** | 局部功能异常；可疑扫描或撞库尝试；依赖组件高危漏洞披露 | 24 小时内处置并记录 |

**升级规则**：Ⅲ 级事件 24 小时内未控制、或认定为同一攻击源持续攻击的，升为 Ⅱ 级。

## 四、监测与预警

**日常监测手段**：

1. 云函数运行日志与错误日志（访问异常、5xx 突增、高频调用）；
2. 接口限流与人机验证拦截计数（异常 IP、异常频率）；
3. 依赖漏洞扫描结果（构建流水线，高危即阻断发布）；
4. 用户举报与反馈（分享页「举报 / 侵权投诉」入口、意见反馈）；
5. 服务可用性探测（首页与分享页 HTTP 状态）。

**预警触发**：出现下列任一情形即进入响应流程——

- 5xx 错误率连续 5 分钟超过 5%；
- 单一 IP 或账号在 1 分钟内触发限流超过 20 次；
- 接到用户或第三方关于数据泄露、内容违规的举报；
- 接到云服务商或主管部门的安全通告。

## 五、处置流程

### 5.1 通用流程

```
发现 → 初步判定分级 → 遏制（止损） → 取证与记录 → 修复 → 报告 → 复盘
```

**第一步：初步判定（30 分钟内）**
确认事件类型、影响范围（是否涉及用户数据、是否涉及内容违规）、是否仍在持续。

**第二步：遏制（1 小时内）**

| 情形 | 处置动作 |
|---|---|
| 账号被盗 / 凭证泄露 | 立即轮换 API Key 与管理密钥，强制失效会话 |
| 异常流量 / 撞库 | 收紧限流阈值，封禁攻击源 IP，开启验证码强制校验 |
| 违法信息传播 | 立即关闭对应分享链接，保留内容快照与发布时间 |
| 服务不可用 | 回滚至上一可用版本，切换静态兜底页并公告 |
| 数据泄露 | 切断泄露通道，保全日志，禁止删除任何记录 |

**第三步：取证与记录（贯穿全程）**
记录时间线、操作人、操作内容、系统日志截图、涉事账号与 IP、影响数据条目数。**原始记录不得修改或删除，保存不少于 6 个月。**

**第四步：修复（24 小时内）**
修复漏洞、更新依赖、调整策略；修复后验证核心链路（登录、同步、分享、支付）。

**第五步：报告**
属于《计算机信息网络国际联网安全保护管理办法》第四条至第七条所列情形，或造成用户个人信息泄露的，**在 24 小时内向属地公安机关网安部门报告**，报告内容包括：事件发生时间、现象、影响范围、已采取措施、后续计划。

涉及个人信息泄露的，同步依据《个人信息保护法》第五十七条通知受影响用户（说明泄露的信息种类、可能后果、已采取的补救措施、用户可采取的措施、联系方式）。

**第六步：复盘（事件结束后 7 日内）**
形成书面复盘：根因、处置得失、改进项与责任人、完成时限。

### 5.2 专项处置

**（一）违法有害信息**

1. 关闭分享链接，停止对外访问；
2. 保存内容快照、发布时间、账号标识、访问日志；
3. 通知发布用户，视情节警告 / 限制功能 / 封禁账号；
4. 涉嫌违法的，24 小时内报告属地公安机关并按要求删除；
5. 记入内容处置台账（来源、内容、结论、动作、时间）。

**（二）用户数据泄露**

1. 立即切断泄露通道，轮换相关密钥；
2. 确定泄露字段与影响用户范围（注意：书签用户名已端到端加密，服务端无明文）；
3. 24 小时内报告公安机关，并按《个人信息保护法》通知用户；
4. 保留全部取证材料，配合调查。

**（三）服务中断**

1. 确认范围（全站 / 单函数 / 单地域）；
2. 回滚版本或重启实例，静态页兜底；
3. 若为云服务商故障，同步提工单并跟踪；
4. 恢复后核对数据完整性（书签数、订单数）。

**（四）支付异常**

1. 暂停下单入口，避免重复扣款；
2. 与支付渠道核对流水，逐笔核对订单状态；
3. 多扣款的立即原路退款；
4. 记录异常订单号与处理结果。

## 六、恢复与演练

**恢复标准**：核心功能（注册登录、云端同步、分享访问、支付下单）全部可用，错误率回落至正常水平，无残留攻击流量。

**数据恢复**：云端数据库每日自动备份，恢复演练每半年一次，验证备份可用性与恢复耗时。

**演练**：每年至少组织一次桌面演练（模拟违法信息传播、数据泄露各一次），记录演练过程与改进项。首次演练于本预案发布后 6 个月内完成。

1. **通讯保障**：应急联络人手机保持 24 小时可达；备用联系方式为 herr@ulink.ren。
