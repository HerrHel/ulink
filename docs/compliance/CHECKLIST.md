## 处置台账写入模板（audit_log）

处置违法/侵权内容时，**先存快照（截图或 curl 存 HTML），再关闭分享**，然后记台账：

```sql
SELECT public.fn_audit_write(
  'report_handle',            -- 动作：举报处置
  '<发布者uid或null>',          -- 若可定位
  'share',                    -- 对象类型
  '<分享gid>',                 -- 对象 ID
  NULL,                       -- ip_hash（可空）
  $${"source":"email","summary":"<违规内容一句话摘要>","action":"share_closed+content_deleted","decided_at":"2026-11-03"}$$::jsonb
);
```

快照文件存 `F://证件//ulink//incidents//`，文件名含日期与分享 gid，保存 ≥6 个月。
