## 一、使用方式

本服务**不自行训练、不微调、不部署自有大模型**，仅通过 API 调用**已在境内完成备案的第三方大模型服务**，用于以下辅助功能：

| 功能 | 说明 |
|---|---|
| 书签智能预填 | 用户保存网址时，自动提取标题与一句话摘要 |
| 分类与标签建议 | 基于用户已有分类给出归类建议，由用户确认后写入 |
| 知识库问答 | 用户就**本人书签与笔记**提问，模型基于这些内容作答 |
| 视频/音频文本整理 | 对用户上传且已获授权的媒体文件做转写文本的要点归纳 |

## 二、不提供面向公众的内容发布

生成内容**仅返回给发起请求的用户本人**，不进入任何公开页面：

- 不存在公开发布、评论区、广场、推荐位、话题聚合；
- 生成内容不写入任何可被第三方检索的公开链接；
- 分享功能为用户主动开启的**私有链接**，且分享页声明 `noindex, nofollow`，不进搜索引擎索引。

因此本服务**不具备舆论属性或社会动员能力**，不构成《生成式人工智能服务管理暂行办法》第十七条所指需开展安全评估并履行算法备案的情形。

## 三、内容安全措施

1. **输入过滤**：接口层校验请求内容与长度，异常请求拒绝；
2. **输出约束**：系统提示限定为书签整理场景，拒绝生成违法违规内容；
3. **频率控制**：按用户账号与 IP 双维度限流，防止批量滥用；
4. **显式标识**：AI 回复下方常显「内容由 AI 生成，仅供整理参考，请自行核实」，符合《人工智能生成合成内容标识办法》（2025-09-01 施行）对显式标识的要求；
5. **用户告知**：《隐私政策》3.3 已告知必要时会将书签片段与对话内容转发至境内第三方大模型服务商；
6. **处置机制**：发现违规生成内容或滥用行为，可限制功能、封禁账号，并保留记录。

## 四、数据与个人信息

1. 仅传递完成当前任务所必需的最小内容，不传全量数据；
2. 不将用户数据用于模型训练；
3. **业务数据（账号信息、云同步数据、上传媒体、订单与日志等）存储于境内**（腾讯云上海地域），不因存储而出境；但**调用链路并非全部在境内完成**：意图寻站、网页元数据提取与海外死链探测由境外边缘节点（Cloudflare）承载，网页网址（URL）、页面公开元数据及部分提示词内容会在该节点处理，相关模型调用由该境外节点发起至境内第三方大模型服务商。应区分「业务数据存储」与「边缘节点处理」，不得笼统表述为「全部数据与调用链路不出境」，详见《隐私政策》3.1、3.3；
4. 用户可在设置中关闭 AI 相关功能。

## 五、结论

本服务对生成式人工智能技术属**工具型调用**，服务于用户个人知识管理，不面向公众发布与传播生成内容，已在产品内落实显式标识与内容安全措施。如主管部门对备案或标识另有具体要求，本单位将按要求补充完善。
