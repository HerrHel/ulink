# 法律文档更新记录（2026-11-07）

## 变更原因

AI Agent 功能专项审计发现三处合规缺口：

1. 隐私政策 §3.3 的「会发送」清单只列 3 类，远小于 `src/lib/ai/mimoPrompt.ts` / `mimoStream.ts` 实际注入的数据类别；且存在按提问关键词触发的隐式情境注入（未打标书签 / 回收站书签）从未告知。
2. §3.3 / §3.4 承诺「可完全关闭 AI 功能」，但代码里只有「隐藏侧边栏入口 / 智能预填 / 语义检索」三个局部开关，`getMiMoConfig()` 恒为 `enabled: true`。
3. 合规文档声称「AI 会话与模型处理不向境外提供」「全部数据不出境」，与 `functions/api/ai-candidates.ts`、`functions/api/extract-metadata.ts` 从 Cloudflare 境外边缘节点发起模型调用、以及 `extract-metadata.ts` 请求 `r.jina.ai` 相矛盾。

本次同步落地代码整改（全局 AI 开关、发送前数据摘要补全、接收方清单）与文本修订。**未新增处理目的或个人信息种类**，属告知完整性与功能口径修订，故生效日期沿用 2026-10-25，仅更新「更新日期」。
